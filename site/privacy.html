Privacy Policy

Last updated: 26 November 2026

Summary

Zycord Client collects no telemetry. Settings are stored as files on your own machine. There is no Zycord account. This website sets no tracking cookies.

The application

  • Zycord Client does not send usage data, diagnostics, crash reports, or analytics to Zynu or to any third party.
  • The app has no telemetry code path and no opt-in for one.
  • Settings, plugin configuration, themes, and QuickCSS rules are written to the local application data folder on your computer. They are not uploaded anywhere by the app.
  • Message logging, when you enable it, writes message data to local storage on your machine. That data stays on your machine.
  • There is no login for Zycord itself. You sign in to Discord inside the app window, and that sign-in is between you and Discord under Discord's own privacy policy.
  • Discord's analytics and crash reporting are blocked by default in the client.
  • Uninstalling the app does not delete the local settings folder. You can remove it yourself.

This website

  • This site is static HTML, CSS, and SVG. It runs no scripts of its own.
  • It sets no tracking cookies and no analytics cookies.
  • The site is served by GitHub Pages, which may process standard request logs such as IP address, under GitHub's own privacy statement.
  • The download button links to a GitHub release file. Downloading from GitHub is subject to GitHub's terms and privacy statement.

Links to other sites

This site links to GitHub and to zynu.me. Those sites have their own privacy practices, and this policy does not cover them.

Children

Zycord Client is not directed at children. Discord's own minimum age rules apply to the account you use with it.

Changes

If this policy changes, the updated date at the top of this page changes with it. The source of this site is public in the repository, so the history of the text can be reviewed.

Contact

Questions about this policy can go to Zynu on GitHub at @izynu, or through zynu.me.
