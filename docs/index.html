Windows desktop client

Your Discord, with 87 plugins already on.

Zycord installs into the Discord desktop app for Windows 10 and 11. It replaces the file Discord loads at startup, adds a plugin system with 87 plugins enabled by default out of 173, then hands control back to Discord. You keep launching Discord exactly as before.

What it does

Six things in the build, each one a setting you can reach from the client's own menu.

01

87 plugins on by default

173 plugins exist in the codebase. 87 of them are enabled the first time the client starts, and each has a settings section in the client.

02

Interface zoom, 50% to 200%

A zoom control scales the whole interface between 50% and 200% while the window stays the same size.

03

Feature Toggles panel

The Feature Toggles panel puts seven switches and a playback speed selector in one place, so those options are changed from the UI rather than a config file.

04

System tray with hide-to-tray

Hiding the window sends the client to the system tray and keeps it running, so you can bring it back without a restart.

05

Message logging

Message logging keeps a record of messages on your machine, stored locally rather than uploaded anywhere.

06

Theme engine and QuickCSS

The theme engine applies CSS themes to the client. QuickCSS is a live editor for your own rules, applied without a reload.

Also in the build: role and permission viewers, profile theming, and Discord analytics blocked by default.

What it is not

  • Not a patch for the official app

    It installs into the Discord you already have. No second window, no second login, and a backup of the original file so uninstalling puts Discord back.

  • Not affiliated with Discord

    Zycord is not affiliated with, endorsed by, or sponsored by Discord Inc. Discord is a trademark of Discord Inc.

  • Not a sanctioned client

    Using a modified Discord client may violate Discord's Terms of Service. The account risk is yours to accept.

Install in three steps

Per-user install, no administrator rights required.

  1. 1

    Run the installer

    Download Zycord-Patcher-Setup-1.0.0.exe, close Discord, and run it. Choose Install. The installer patches Discord in place and keeps a backup of the original file.

  2. 2

    Clear the SmartScreen warning

    The build is unsigned, so Windows shows a warning. Choose "More info", then "Run anyway", if the file came from the download link on this page.

  3. 3

    Launch and sign in

    Start Zycord from the Start menu or the desktop shortcut, then sign in to Discord inside the app window.
